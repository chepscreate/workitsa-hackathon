# WorkitSA — FNB Hackathon 2026 Demo Video Script

**Hard limit: 90 seconds.** Voiceover is ~180 words (≈70s at a calm pace), leaving
~20s of screen action/breathing. Don't rush — the buffer is deliberate.

> **This script matches the LIVE-TESTED flow (20 Oct 2026).** Every WhatsApp beat
> below was verified end-to-end on the real system — just re-record the same taps.

- **Format:** 16:9 landscape, 1920×1080. Show the phone screens inside a simple
  device frame on a cream (#faf4ec) background.
- **Audio:** clear voiceover (record separately, lay over the screen capture) + soft
  background music. **Captions ON the whole time** (low-data viewers watch muted).
- **Host it:** YouTube **unlisted** or Google Drive "anyone with link" → paste that
  link on deck slides 6 and 10. Test the link in incognito before submitting.

### ⚙️ Before you record (WhatsApp setup)

  test line (add it in Meta → WhatsApp → API Setup → *To*; max 5). The founder can add
  Simphiwe's number.
- **Save the WorkitSA line (`+1 555 667 9905`) as a contact named "WorkitSA Jobs"** on
  that phone *before* recording — so the chat header reads **"WorkitSA Jobs"**, not a raw
  US test number. (A real SA number replaces this after the hackathon.)
- Do a full dry run first (JOBS → 1 → START → DONE), then clear the chat and record it clean.

## Exact taps to re-record (the proven flow)

From the recording phone's WhatsApp → the **WorkitSA Jobs** contact:

1. Send **`JOBS`** → wait for the numbered list of open jobs.
2. Send **`1`** → wait for **"✅ Offer sent…"**.
3. *(Founder accepts the offer behind the scenes so the next steps unlock — or it's
   pre-arranged before recording.)*
4. Send **`START`** → wait for **"👍 Marked … as started…"**.
5. Send **`DONE`** → wait for **"🎉 Marked … as done…"**.
6. Wait for the **"🎉 … Here's your Work Record …"** message → **tap the link** → let the
   Work Record page load, then slowly scroll it once.

## Recording tips
- **Screen-record on the phone** (Android built-in recorder) for the WhatsApp beats —
  it looks authentic. Capture Live Pulse / Jarvis on desktop.
- **Record the voiceover separately** in a quiet room, then sync — narrating live while
  tapping always runs long.
- **Keep captions short** — echo the caption column, not the full VO.
- **Watch the clock:** export, confirm **under 90 seconds** before uploading. If over,
  trim beat 1 b-roll or beat 6 — **never** the WhatsApp offer or the Work Record beat.
